Gradient Background Webpage

Linear and radial gradients with fixed attachment

Linear Gradient

A linear gradient creates a smooth color transition along a straight line. Here the background goes from teal to deep blue at a 135-degree angle. The colors blend evenly from one corner toward the opposite corner, which works well for hero banners and full-page backgrounds.

Syntax example: linear-gradient(135deg, #11998e, #38ef7d, #1a2980). You can set direction with angles or keywords like to right and to bottom.

Radial Gradient

A radial gradient spreads outward from a center point in a circular or elliptical shape. This section uses a radial gradient with a warm center fading into cooler outer colors for a spotlight effect.

Syntax example: radial-gradient(circle at center, #f6d365, #fda085, #2c3e50). background-attachment: fixed keeps the gradient pinned while you scroll, creating a simple parallax-like feel.
