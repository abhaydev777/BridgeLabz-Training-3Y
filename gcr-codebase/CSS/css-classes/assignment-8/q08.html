Box-Sizing Comparison

Same width, padding, and border — different sizing models.

content-box

width: 250px
padding: 30px
border: 10px

Total width = 250 + 60 + 20 = 330px

border-box

width: 250px
padding: 30px
border: 10px

Total width stays 250px

What's the difference?

With content-box (the browser default), width only covers the content area. Padding and border are added on top, so the element grows wider than 250px.

With border-box, width includes padding and border. The outer size stays fixed at 250px, which makes layout calculations much more predictable.
