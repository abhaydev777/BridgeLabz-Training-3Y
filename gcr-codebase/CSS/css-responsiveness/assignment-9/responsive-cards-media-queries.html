Responsive Card Layout

Resize the browser to see 4 → 2 → 1 column breakpoints.

Flexbox

Distribute space along one axis. Ideal for navbars, rows of cards, and equal-height columns.

CSS Grid

Control both rows and columns at once. Great for page-level layouts and galleries.

Media Queries

Change styles at specific widths so the same HTML works on phones, tablets, and desktops.

Filters

Apply visual effects like blur, grayscale, and contrast directly in CSS without editing images.
