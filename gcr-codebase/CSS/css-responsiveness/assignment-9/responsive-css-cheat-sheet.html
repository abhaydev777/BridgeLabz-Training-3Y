CSS Responsiveness Cheat Sheet

Quick reference for filters, media queries, layout, and typography.

Filters

blur()
Softens the image. Example: filter: blur(4px);
grayscale()
Removes color. Example: filter: grayscale(100%);
sepia()
Warm vintage tone. Example: filter: sepia(80%);
brightness() / contrast()
Adjust light and detail. Example: filter: brightness(1.2) contrast(1.3);

Media Queries

Basic syntax
@media (max-width: 600px) { ... }
min-width
Styles apply from that width upward (mobile-first).
max-width
Styles apply from that width downward (desktop-first).
Common breakpoints
600px (mobile), 750–900px (tablet), 1100px+ (desktop).

Responsive Design

Fluid layouts
Use %, fr, auto-fit, and flex/grid instead of fixed px widths.
Flexible media
img { max-width: 100%; height: auto; }
Viewport meta
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Relative units
Prefer rem, em, vw, and % for scalable spacing.

Typography

clamp()
font-size: clamp(1rem, 2vw, 1.5rem);
Line height
Body text often works well around 1.5 to 1.7.
Readable measure
Limit paragraph width (~45–75 characters) with max-width.
Contrast
Keep text dark enough on light backgrounds for accessibility.
