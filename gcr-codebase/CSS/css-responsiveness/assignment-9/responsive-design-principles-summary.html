Responsive Design Principles

Three building blocks every responsive page needs.

Fluid Layouts

Layouts that use relative units and flexible tracks so columns resize with the viewport instead of staying locked to fixed pixel widths.

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 1rem;
}

Flexible Media

Images and video should shrink to fit their parent. Avoid overflow by capping width and letting height scale automatically.

img, video {
  max-width: 100%;
  height: auto;
  display: block;
}

Breakpoints

Media queries redefine layout and spacing at key widths so navigation, grids, and typography stay usable on each device class.

@media (max-width: 600px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
